# Sistema de Nómina (ERP académico)

Módulo de nómina de un ERP desarrollado en el curso de Análisis de Sistemas II, Universidad Mariano Gálvez de Guatemala. Cada grupo construye un módulo sobre una base de datos Oracle compartida. Proyecto en desarrollo, hecho por un equipo de 6 personas.

El código está en un repositorio privado del equipo. Este repositorio describe el proyecto y mi aporte, con capturas de datos de ejemplo.

## Arquitectura

- Frontend: React con Vite.
- Backend: Node.js con Express y TypeScript.
- Base de datos: Oracle Database 23ai Free.
- Entorno de desarrollo: Oracle Linux 8 en una máquina virtual de VirtualBox, con Nginx y PM2, accedida por SSH desde VS Code.

## Mi aporte

- Generación de archivos de transferencias bancarias y reportes del IGSS (Seguro Social de Guatemala).
- Diseño de las tablas de mi parte del módulo a partir del script de base de datos del equipo, con revisión de campos y catálogos que faltaban.
- Datos de prueba y corrección de problemas de codificación de acentos en Oracle.
- CRUD de frontend y backend de mis tablas (en progreso).
- Configuración del entorno de desarrollo y despliegue local.

## Metodología

Scrum y XP, con seguimiento de tareas en Jira.
